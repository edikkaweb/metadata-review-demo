# Contribuer / Contributing

Ouvrez une issue avec la page, la langue, les étapes et le résultat attendu. Pour une correction, indiquez les commandes réellement exécutées et leur résultat. Les commandes de démarrage et de contrôle sont dans le README et la documentation du projet.

Préservez les parcours FR/EN et l’accès clavier. Les archives, observations et corpus historiques restent inchangés : une nouvelle mesure doit être datée, distincte et accompagnée de son protocole. Les licences du code, des données et des marques conservent leur périmètre. Ne publiez aucune donnée personnelle ni aucun secret dans une issue.

**English.** Please include the page, language, reproduction steps and expected result. Report the checks you actually ran. Preserve both languages and keyboard access. Keep historical evidence unchanged; new measurements need a separate dated record and protocol. Existing licence scopes remain in force. Never include personal data or credentials in public issues.
